# ゲーム音声（2026-09-28）

音源はアプリの固定BGM・操作音として使用する。生成プロンプト、事件JSON、保存ゲーム、教材の出力データには含めない。

## 選曲と操作

| 場面 | 同梱曲 | OpenTracksの手動取込後 |
| --- | --- | --- |
| タイトル・設定・制作入力 | Secret Corridor | Insight |
| 生成・検証中 | Secret Corridor（低音量） | プラネタリウムガーデン |
| 調査・再調査 | Secret Corridor | 同じ |
| 初回法廷・再審理 | Ticking Labyrinth | 危機 |
| 判決・解説 | Secret Corridor（低音量） | 真実の証明 |

空白の音は、暗すぎるという利用者のコメントを踏まえて不採用。その他の候補は切替の頻度と容量を抑えるため今回は同梱しない。

最初のクリック・キー入力でWeb Audioを開始する。BGMはループし、異なる曲への切替を0.9秒でフェードする。同じ曲を使う場面間では音量だけを変えて再生を継続する。画面再描画では再スタートしない。タブ非表示時は停止し、復帰時に再開する。

サウンドメニューと制作画面の設定から全音声ミュート、BGM・効果音の個別音量を操作できる。初期値はBGM35%、効果音40%（さらに場面別の音量係数を適用）。設定はこのブラウザのlocalStorageに保存する。保存できない場合でもそのページ内で調整は有効。音声が使えない場合もプレイは継続する。

効果音はボタン決定・保存・開始・選択変更・次のメッセージに割り当て、成功音は生成READYへの遷移またはサーバーが返したクリア結果で鳴らす。文字送りの一文字ごとやポインタ移動では鳴らさない。

## 出典・条件確認

2026-09-28に利用者が指定した配布ページと以下の条件を確認した。

- [PeriTune](https://peritune.com/about/)：今回の2曲はいずれも2026年3月以降の独自規約対象。無料配布版をゲームBGMとして使用する。単体素材としての再配布・販売やContent ID登録には使用しない。有料WAV版は使わない。
- [効果音ラボ](https://soundeffect-lab.info/agreement/)：ゲームの操作音として利用。外部音源URLへの直リンクはせずローカル同梱する。素材配布機能や生成コンテンツへの音源出力は追加しない。
- [OpenTracksのライセンス](https://opentracks.com/help/articles/license/)および[サイト利用規約](https://opentracks.com/help/articles/terms/)：自動収集禁止のため音源は自動ダウンロードしない。現時点では同梱していない。手動取込前に各作者の追加条件も確認する。第三者向け制作ツール・二次利用ライセンスに関する条件があるため、音源のエクスポート機能を追加する場合は別途確認が必要。

配布元の音源はMP3/OGGのまま公開せず、AES-GCMでゲーム用`.bin`にパッケージする。再生鍵はクライアントにあるため抽出防止を保証するDRMではない。ゲーム付随の再生専用とし、音源一覧からの試聴・音源ダウンロード機能は提供しない。著作権・利用規約はコードのライセンスと区別する。

`public/assets/audio/manifest.json`に原曲ページ、利用条件、元音源と格納ファイルのSHA-256を記録する。画面の「音楽・効果音のクレジット」から配布元へ移動できる。

## 手動取得した音源の取込

作者別の条件確認後、ローカルに取得済みのファイルを指定する。取り込みスクリプトはネットワークアクセスを行わない。

```powershell
node scripts/import-game-audio.mjs insight "C:\path\Insight.mp3"
node scripts/import-game-audio.mjs garden "C:\path\プラネタリウムガーデン.mp3"
node scripts/import-game-audio.mjs crisis "C:\path\危機.mp3"
node scripts/import-game-audio.mjs truth "C:\path\真実の証明.mp3"
```

`node`がWindows側にない環境ではWSLのNodeと`/mnt/c/...`形式のパスを使用する。ループ専用版が配布されている場合はそちらを選ぶ。MP3、OGG、WAVを受け付けるが、権利条件の異なる有料音源を誤って指定しない。取込後はクレジットに作者・曲の出典を追加し、サーバーを再起動して再読み込みする。

取込結果は音源とmanifestの組で管理する。外部配布前には用途に合わせて最新の規約を確認する。
