# 第三者調査報告方式の廃止

この文書で以前定義していた、第三者の直接観察を記した調査報告をプレイヤーが取得・保存・提出する方式は、2026-10-01に廃止した。

## 廃止理由

- 各攻撃の通常の技術資料に加えて人物帰属用の報告書を選ばせるため、証拠選択が不必要に複雑になっていた。
- どの攻撃でも同種の報告書が必要となり、攻撃ごとのログや端末情報を読み解く学習体験を弱めていた。
- 技術資料が示す処理と、人物を直接見たという証言を混在させ、技術資料だけでは人物を断定できないという教材上の重要な限界を曖昧にしていた。

## 現在の方針

- プレイヤーが取得・保存・提出するのは、攻撃定義に登録されたメール、Web記録、認証記録、端末記録、設定、ファイル等の技術資料だけとする。
- 技術資料から、攻撃の処理経路・対象・結果と、各記録が直接示せる範囲を確認する。
- 検察側が主張する被告人による準備・作成・直接操作が技術資料から確認できず、第三者による操作、認証情報の悪用、誘導又は自動処理の可能性を排除できない場合、その合理的な疑いを無罪判決の根拠とする。
- 「第三者が実行した」と断定したり、技術資料だけから第三者を特定したりすることは正解条件にしない。
- 内部のGround Truthは、取得できない証拠の代用としてプレイヤー向け論証へ持ち込まない。
- 必要な技術資料や資料間の対応関係が不足する場合は、報告書で補わず生成を差し戻す。

全16攻撃の必要資料と取得経路は、[全16攻撃の技術証拠監査](technical-evidence-audit-2026-10-01.md)に記録する。
