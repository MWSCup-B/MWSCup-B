# 証拠の探索を中心にした学習（2026-09-27）

今回の利用者要求を優先し、9月25日仕様の「正しい調査操作の選択後に原文を取得」「問題文に基礎説明を組み込む」「争点解決直後の詳しい解説」を変更した。プレイ中は資料を探って判断し、詳しい説明は終了後に読む。

## 調査と反論

- OPEN_MATERIALSでは、資料一覧から原文を開くと全文が読める。既存の取得条件を満たさない資料は取得できない。閲覧は`inspect-material`の`read`操作で記録する。
- 検索は表示済み原文に対する大文字小文字を区別しない文字列検索。空白区切りはAND検索。行番号と該当行数を表示し、全文へ戻せる。本文・SQL・HTML・検索語を実行せず、原文も変更しない。
- 検察側の主張と反論4択は`currentRound`に対応する争点で固定する。資料の切り替えで別争点の設問へ変わらない。資料と反論の組合せは従来のバックエンド規則で判定する。
- 操作の2～4択、解法を説明する問題文、途中の成功解説は表示しない。旧保存形式の調査手順は互換用に残し、終了後の読み解き例に利用する。
- 新規生成の反論候補にStored XSSやSQLインジェクション等の手口名を含めると差し戻す。旧保存データの該当名称は反論の表示時だけ伏せ、元の正解ID・証拠本文は維持する。
- 2026-09-28以降の新規ログはWeb・DB・認証・アプリ・通信それぞれ最低100件、生成目安100～120件の異なる記録を含める。既存の取得元・記録条件内の背景記録だけを認め、技術的な成立条件、因果、人物帰属を補う根拠にはしない。件数不足は生成側へ返し、封印済み資料を後処理で水増ししない。[被害原因の新設計](incident-experience-2026-09-28.md)を参照。以下の過去の検証結果の件数は当時のもの。

## SQLインジェクション

Webの記録条件は時刻と要求対象を保証しているが、入力本文を保証していない。学習要件を、対象要求と対応するDB監査の実行SQLの識別情報、および`statement`（同義の`sql`・`query`）欄の条件・構造の読解へ統一した。未記録の入力、通常SQLの比較例、相関IDを必須にしない。未確認の対応や被害は追加しない。技術検証と独立レビューの差し戻し機能は維持する。

報告書には「意図しない条件のデータベース処理が実行された」という発生事象を示し、手口名は伏せる。提出資料はWeb記録だけに限定せず、調査可能な資料一覧を提示する。原文は調査で開く。

## 終了後と保存一覧

判決画面に明示的な「解説」欄と「ゲーム終了」リンクを設け、後者はサーバーを停止せず`/author#court`の保存一覧へ戻る。解説は事件の仕組み、資料の用語、調査例、各争点の主張、正確な原文引用、成立する反論と説明を分ける。生成する説明には用語、比較手順、各候補の読み違い、判断限界を平易な日本語で求める。

保存一覧の「解説資料」は中央のネイティブdialogで開く。本文を独立スクロールでき、閉じるボタンとEscapeで閉じ、起点へフォーカスを戻す。未クリアの解説APIのアクセス制限は維持する。

生成失敗・中止後のメニュー遷移を許可し、制作条件を保持しつつ未完成の成果物を破棄する。処理中のリセットは拒否する。古い状態更新が遅れて返っても、新しい画面状態を上書きしない。

## 適用範囲

全文表示、検索、争点の固定、モーダル、終了リンクは既存のOPEN_MATERIALS保存ゲームにも適用する。生成済みの証拠本文・正解・保存済みの事件説明は変更しない。ログ件数、修正されたSQL要件、報告書、詳細な生成解説を反映するには再生成が必要。

技術説明の確認先：

- [OWASP SQL Injection Prevention](https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html)
- [OWASP Cross Site Scripting](https://community.owasp.org/attacks/xss/)
- [OWASP Logging](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html)

自動検査は構造、参照、操作経路、情報公開を確認する。生成文の意味と日本語の品質すべてを機械的に保証するものではない。
