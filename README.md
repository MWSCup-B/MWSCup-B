# インシデントクラフト

**作って！解いて！攻撃を学ぶ！**

セキュリティインシデントの調査と裁判を通して、攻撃の仕組みと証拠の読み解き方を学ぶローカルWebゲームです。攻撃手法と舞台を選ぶと、AIによる生成・検証とサーバー側の検証を組み合わせて事件を作成します。

プレイヤーは被告人の弁護側となり、探偵パートでログやメールなどを調査し、法廷パートで証拠に基づく反論を示して無罪を目指します。クリア後は解説資料で復習できます。

## 起動方法

### 1. 初回の準備

Node.js **22以上**、npm、Webブラウザを用意し、このリポジトリのフォルダーでターミナルを開きます。新しいゲームの生成には、Codexへのログインとネットワーク接続が必要です。

依存関係をインストールします。Codex CLIも同時にインストールされます。

```sh
npm ci
```

未ログインの場合は、次のコマンドを実行し、表示される案内に従って認証してください。ログイン済みなら省略できます。

```sh
npx codex login
```

### 2. サーバーを起動する

```sh
npm start
```

ターミナルは開いたまま、ブラウザで [http://localhost:3000](http://localhost:3000) にアクセスします。「インシデントクラフト」のタイトル画面が表示されたら準備完了です。2回目以降は、通常 `npm start` から始められます。

Windows PowerShellでは、`npm`・`npx` を `npm.cmd`・`npx.cmd` に置き換えられます。起動できない場合は、Node.jsのバージョンと、ポート3000で別のサーバーが動いていないか確認してください。

## 遊び方

### 1. 事件を作成する

1. タイトルの **「Game Start!」**を押し、「ゲーム作成」の **「攻撃と舞台を選ぶ」**へ進みます。
2. 攻撃手法を1～3件と事件の舞台を選びます。2件目以降には、前の攻撃から続けられる候補が表示されます。1件だけで作る場合は、後続の攻撃を追加しません。
3. **「Scenario案を作成」**を押し、検証が終わるまで待ちます。「生成モデル」と「エフォート」は、必要がなければ既定のままで開始できます。
4. **「Scenario Preview」**で、事件概要・攻撃手法・調査方法・ネットワーク構成図を確認します。選び直す場合は **「条件を修正」**で戻ります。
5. 内容がよければ **「このScenarioでゲームを作成」**を押します。「ゲームが完成しました」と表示されたら、**「ゲームをプレイする」**で開始します。

攻撃はフィッシング、Stored XSS、不正ログイン、ClickFix、SQLインジェクション、パスワードスプレー、ランサムウェア、不正ファイルアップロードの8種類です。舞台は企業・行政機関・学校・大学／研究機関・医療機関から選べます。

生成中は進捗が表示されます。中止する場合は「生成を中止」、失敗した場合は理由を確認して「攻撃と舞台の選択へ戻る」を選びます。

### 2. 事件報告書を読む

**「事件ファイルを開く」**を押し、事件報告書の「被害の概要」「被告人に対する嫌疑と根拠」「提出資料」「関係者の供述」を確認します。何が起きたとされ、なぜ被告人が疑われているのかを押さえてください。

**「報告書を読んで調査へ」**で探偵パートへ進みます。会話が表示された場合は「次の台詞」で読み進め、「調査を始める」を押します。

### 3. 資料を調べる

1. **「機器・資料を選ぶ」**から、調べたい端末やサーバーの資料を開きます。
2. ログの画面では **「Template」**から読み取り・検索用の疑似コマンドを選び、**「実行」**を押します。メールなどは資料を開くと本文が表示されます。
3. **「前ページ」「次ページ」**で記録を読み、時刻・送信先・処理IDなどをほかの資料と照合します。
4. 別の資料へ移るときは **「現場へ戻る」**を押します。

疑似コマンドはゲーム内の「Command Composer」に入力します。たとえば、次の操作で全文表示や文字列検索ができます。

```text
cat material.txt
grep -F "検索する文字列" material.txt
```

「保存値」で記録中の値を保存すると、ほかの資料の検索にも利用できます。「History」では実行済みの検索を見直せます。調査に迷ったら、**「Talk」**で現在の主張、**「Hint」**で調べ方のヒント、**「ネットワーク構成図」**で機器の関係を確認してください。

### 4. 原文を証拠として保存する

**資料の閲覧や「保存値」の操作だけでは、法廷に提示する証拠は保存されません。**

1. 調査中の資料で **「原文を証拠として保存」**を押します。
2. 根拠にする行の **「行○を証拠として保存」**を押します。資料全体を保存する場合は **「この資料の全○行を一括保存」**を使います。
3. 上部の **「保存済み原文」**の件数や、**「Notes」**の「保存した証拠」で保存内容を確認します。

「必要資料の保存完了」は、必要な種類の資料を保存したことを示します。反論を裏付ける原文が十分かどうかは、法廷で提示したときに判定されます。

### 5. 反論を選び、法廷で提示する

1. **「保存した証拠を基に反論を考える」**を押します。
2. 検察側の主張と保存した証拠を読み比べ、4つの選択肢から記録に基づく反論を選びます。
3. **「この反論で法廷へ」**を押します。押せない場合は、反論の選択と、今回の争点に必要な資料の保存を確認してください。
4. 法廷で反論と証拠を確認し、**「保存した証拠一式を提示する」**を押します。

提示前なら **「調査に戻って推理を選び直す」**から、回数を消費せずに追加調査できます。提示が不成立だった場合は **「調査室へ戻って再検討」**から証拠と反論を見直します。各争点の提示上限は3回です。

争点を解決すると次の調査へ進みます。保存する原文は争点ごとにリセットされるため、次の争点に必要な証拠を改めて保存してください。すべての争点を解決すると無罪判決となります。

### 6. 解説・再プレイ・終了

クリア後は会話を読み進め、**「判決を確認する」→「解説を開く」**で事件の経緯と資料の読み解き方を振り返れます。

完成したゲームは `data/saved-games/` に自動保存されます。再プレイするときは **「Game Start!」→「裁判へ進む」→「このゲームで遊ぶ」**と進みます。クリア済みのゲームは、保存一覧の **「解説資料」**からも復習できます。

判決画面の「ゲーム終了」は保存一覧へ戻ります。サーバーも停止する場合は、モード選択画面のメニューから「ゲーム終了」を選ぶか、起動したターミナルで `Ctrl+C` を押してください。制作・プレイ途中の進行はサーバー再起動で失われ、プレイ画面の再読み込みでも最初から開始します。
